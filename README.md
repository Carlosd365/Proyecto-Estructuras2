## 📌 Objetivo
Crear un sistema en Python que permita registrar, buscar y listar proveedores de servicios usando un **Árbol B**, simulando plataformas de contratación bajo demanda.

---

## 📂 Archivos
- **ArbolB.py** → Implementación del Árbol B y NodoB.  
- **Proveedor.py** → Clase que define los proveedores.  
- **Menu.py** → Interfaz de consola para interactuar con el sistema.  

---

## 📋 Funcionalidades
- Insertar nuevos proveedores.  
- Buscar proveedores por tipo de servicio.  
- Listar proveedores ordenados (por nombre o calificación).  
- Mostrar la estructura del Árbol B por niveles.
